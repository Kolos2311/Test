# BTCUSDT auto-trading bot

Цель проекта — полностью автоматический торговый бот для BTCUSDT (Binance USDT-M futures).

**Этап 1 (текущий): независимое исследование.** Ищем комбинации индикаторов, которые
на истории давали сделки в обе стороны (лонг и шорт) с фиксированными уровнями:

| параметр     | значение                                |
|--------------|-----------------------------------------|
| тейк-профит  | 1% чистого движения цены (без плеча)     |
| стоп-лосс    | 0.25% чистого движения цены              |
| цель         | win rate ≥ 75%, топ-5 комбинаций          |

Этап 2 — проверка топ-5 на реальных данных (paper trading), этап 3 — сам бот.

## Как устроен бэктест

* Данные: минутные свечи Binance USDT-M futures BTCUSDT с `data.binance.vision`, 2019-10 → сегодня.
* Сигнал считается по **закрытию** свечи таймфрейма (5m / 15m / 30m / 1h / 4h);
  старшие таймфреймы (1h / 4h / 1D) берутся только по уже закрытым свечам.
* Вход — по open следующей минутной свечи. Дальше минута за минутой проверяется,
  что раньше коснётся: TP или SL. Если обе цены внутри одной минутной свечи —
  порядок неизвестен, сделка считается **убыточной** (консервативно).
* Одна позиция одновременно; сигналы во время открытой сделки пропускаются.
* WR считается по чистому движению цены. Доходность показывается и «грязной»,
  и за вычетом комиссии taker 0.05% × 2.
* Безубыточный WR при TP 1% / SL 0.25%: 20% без комиссий, 28% с комиссиями taker.

### Протокол отбора (защита от подгонки)

| период     | годы          | для чего                                                    |
|------------|---------------|-------------------------------------------------------------|
| train      | 2020–2023     | перебор всех комбинаций 1–3 условий (+ расширение до 4)        |
| validation | 2024          | проверка лучших; финальный рейтинг строится по train+validation |
| test       | 2025 → сейчас | выбранная пятёрка прогоняется один раз, результат как есть        |

Плюс **нулевой бенчмарк**: тот же поиск на реальных данных, где направление каждой
минутной свечи случайно перевёрнуто (`--null-seed`). Волатильность, объёмы и диапазоны
свечей те же, предсказуемости нет. Сколько WR поиск «находит» там, столько даёт
чистая подгонка; реальная стратегия должна быть заметно лучше.

## Структура

```
btcbot/
  data.py         загрузка/кэш свечей, ресемплинг, нулевой датасет
  indicators.py   индикаторы (EMA, RSI, MACD, BB, Keltner, Stoch, ADX, Supertrend, PSAR,
                  Ichimoku, CCI, MFI, Williams %R, VWAP, OBV, z-score, ...)
  conditions.py   ~75 условий входа: тренд, импульс, возврат к среднему,
                  поток ордеров (taker buy), режим волатильности, сессия, старший ТФ
  engine.py       разрешение TP/SL на минутках, симуляция «одна позиция за раз»
  search.py       перебор комбинаций через битсеты (numba)
  metrics.py      WR, доверительный интервал Уилсона, биномиальный тест, PF, просадка
research/
  fetch_data.py   скачать данные
  run_research.py поиск, валидация, тест, отчёт в reports/
tests/            проверки движка, отсутствия заглядывания в будущее, скринера
```

## Запуск

```bash
pip install -r requirements.txt
python -m research.fetch_data                          # ~85 архивов, ~3.7 млн минутных свечей
python -m research.run_research --out reports          # реальные данные
python -m research.run_research --null-seed 1 --out reports/null   # нулевой бенчмарк
python -m pytest -q
```
