# BTC-бот для Hyperliquid

Автоматический торговый бот для BTC-перпетуала на Hyperliquid и независимое
исследование, по которому подобраны его стратегии.

* **Результаты исследования:** [`reports/RESULTS.md`](reports/RESULTS.md). Прочитайте их до запуска на реальные деньги.
* **Боты:** 5 конфигураций в [`bots/`](bots/), по умолчанию все в режиме `paper` (без денег).

| бот | ТФ | условия (лонг; шорт зеркально) | WR на данных, не участвовавших в отборе | статус |
|-----|----|--------------------------------|------------------------------------------|--------|
| bot4 | 15m | close>EMA200 + +DI>−DI + Stoch K<10 + сессия EU | 32.2% (87 сделок, p 0.007) | подтверждён |
| bot5 | 15m | close>EMA200 + Stoch K<10 + MFI<20 + выходные | 29.9% (157, p 0.003) | подтверждён |
| bot2 | 15m | +DI>−DI + ≥4 падающих свечи + сжатие BB + 1D RSI>50 | 28.8% (111, p 0.022) | подтверждён |
| bot1 | 1h | выше облака Ichimoku + Stoch K×D в перепроданности + низкий ATR | 21.4% (140, p 0.42) | только paper |
| bot3 | 30m | пробой Donchian55 + RSI14>70 + импульс + ADX<20 | 23.5% (187, p 0.17) | только paper |

WR 75% при TP 1% / SL 0.25% не найден: безубыточность при таком соотношении около 27%
с комиссиями, а лучшие устойчивые стратегии дают около 30%. Подробности в отчёте.

Параметры сделки везде одинаковые: тейк-профит 1% и стоп-лосс 0.25% чистого движения цены
(без учёта плеча), торговля в лонг и в шорт, одна позиция на бота.

## 1. Боты

### Как бот торгует

1. Ждёт закрытия свечи своего таймфрейма (5m / 15m / 30m / 1h / 4h).
2. Скачивает с Hyperliquid последние закрытые свечи (1500 своего ТФ, по 300 старших ТФ)
   и считает условия **тем же кодом, что и бэктест** (`btcbot/conditions.py`).
   Тест `tests/test_live.py` проверяет, что сигналы на «живом» окне совпадают с бэктестом.
3. Если все условия стратегии выполнены для лонга (или для шорта), входит по рынку
   (IOC-ордер с ограничением проскальзывания 0.3%). Если бот запустился позже чем через минуту
   после закрытия свечи, этот сигнал пропускается: в бэктесте вход был на следующей минуте.
4. Сразу ставит на бирже два reduce-only триггер-ордера: TP +1% и SL −0.25% от цены исполнения.
   Если поставить стоп не удалось, позиция сразу закрывается: без стопа бот не сидит.
5. Каждые 15 с сверяется с биржей. Закрылась сделка — пишет её в журнал и снимает
   оставшийся ордер. Пропал TP/SL — ставит заново. После перезапуска подхватывает
   открытую позицию и защищает её.

### Защита

| что                          | где в конфиге                  | что делает                                                   |
|------------------------------|--------------------------------|--------------------------------------------------------------|
| размер позиции               | `notional_usd`                 | стоимость позиции в USD (минимум биржи — 10 USD)              |
| жёсткий потолок              | `max_notional_usd`             | бот не запустится, если размер больше                         |
| дневной лимит убытка         | `max_daily_loss_usd`           | до конца суток UTC новых входов нет                           |
| серия убытков                | `max_consecutive_losses`       | пауза до ручного `--reset-risk`                               |
| mainnet                      | `HL_CONFIRM_MAINNET=yes`       | без этой переменной режим `mainnet` не запускается             |
| аварийная остановка          | файл `state/<бот>/STOP`        | бот снимает ордера, закрывает позицию и останавливается        |
| разные боты — разные счета    | проверка при старте            | на одном счёте Hyperliquid позиция по BTC общая, поэтому два бота на одном счёте не запустятся |

Ctrl+C останавливает ботов, но открытые позиции остаются с биржевыми TP/SL.

### Установка

Нужен Python 3.11+ и доступ к `api.hyperliquid.xyz`.

```bash
git clone https://github.com/Kolos2311/Test && cd Test
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q
```

### Шаг 1 — paper (без денег, без ключей)

```bash
python -m btcbot.live bots/*.toml --check   # проверить конфиги и текущие сигналы
python -m btcbot.live bots/*.toml           # запустить все 5 ботов на бумаге
python -m btcbot.live.stats                 # результаты ботов против бэктеста
```

Сделки симулируются на живых ценах Hyperliquid по правилам бэктеста. Журнал:
`state/bot1/trades.csv` и так далее, общий лог `bots.log`.

### Шаг 2 — testnet

1. Зайдите на https://app.hyperliquid-testnet.xyz и получите тестовые USDC в разделе Faucet
   (Hyperliquid может требовать, чтобы у адреса уже был депозит в mainnet).
2. В разделе **API** создайте API-кошелёк (agent) и одобрите его. Его приватный ключ
   используется только для подписи ордеров и не может выводить средства.
3. Задайте ключи. Не храните их в файлах репозитория.
   ```bash
   export HL_SECRET_KEY=0x...          # приватный ключ API-кошелька
   export HL_ACCOUNT_ADDRESS=0x...     # адрес основного кошелька
   ```
4. Раздайте ботам отдельные счета: у каждого бота должен быть свой счёт.
   * **Субаккаунты** (раздел Sub-Accounts в интерфейсе Hyperliquid): адрес субаккаунта
     впишите в `subaccount_address` нужного бота и переведите на него USDC;
   * **или отдельные кошельки:** в конфиге бота укажите `secret_env = "HL_SECRET_KEY_BOT2"`
     и `account_env = "HL_ACCOUNT_ADDRESS_BOT2"`, затем экспортируйте эти переменные.
5. В конфигах поставьте `mode = "testnet"` и запустите ботов.

### Шаг 3 — mainnet

Поставьте `mode = "mainnet"`, задайте `export HL_CONFIRM_MAINNET=yes` и начните
с минимального `notional_usd` (20 USD). Запускать лучше на сервере в `tmux` или
как службу systemd:

```ini
# /etc/systemd/system/btcbot.service
[Service]
WorkingDirectory=/opt/btcbot
EnvironmentFile=/opt/btcbot/.env
ExecStart=/opt/btcbot/.venv/bin/python -m btcbot.live bots/bot1.toml bots/bot2.toml bots/bot3.toml bots/bot4.toml bots/bot5.toml
Restart=always
```

## 2. Исследование

### Данные

Из облачной среды разработки Binance и Hyperliquid недоступны, поэтому исследование
проведено на минутных свечах **Bitstamp BTC/USD** (публичный архив
[ff137/bitstamp-btcusd-minute-data](https://github.com/ff137/bitstamp-btcusd-minute-data),
2019-10 → 2026-10, 3,7 млн свечей). Цена BTC на крупных площадках движется синхронно,
поэтому для движений 1% и 0.25% это корректная замена. 216 одиночных «шпилек» шире 1.5%
(плохие тики тонкого стакана) обрезаны. Загрузчик Binance (`research/fetch_data.py`) тоже есть:
на машине с доступом к Binance всё перезапускается одной командой.

### Бэктест

* сигнал по закрытию свечи ТФ, вход по open следующей минуты;
* TP/SL проверяются минута за минутой; если обе цены в одной минуте — сделка **убыточная**;
* одна позиция за раз; комиссия Hyperliquid taker 0.045% × 2;
* безубыточный WR при TP 1% / SL 0.25%: 20% без комиссий, ≈27% с комиссиями.

### Защита от подгонки

* разбиение train 2020–2023 / validation 2024 / test 2025–2026;
* walk-forward: отбор на 24–36 месяцах, торговля следующие 6 месяцев, сдвиг на 6 месяцев;
* **нулевой бенчмарк:** тот же поиск на данных, где направление каждой минуты случайно
  перевёрнуто. Волатильность та же, предсказуемости нет. Это показывает, сколько WR
  даёт сама подгонка.

### Запуск

```bash
python -m research.import_bitstamp /path/to/bitstamp-btcusd-minute-data
python -m research.run_research  --data BTCUSD-bitstamp --out reports/bitstamp
python -m research.run_research  --data BTCUSD-bitstamp --null-seed 1 --out reports/bitstamp-null1
python -m research.walk_forward  --data BTCUSD-bitstamp --out reports/walk_forward_t24_m40
python -m research.family_test   --data BTCUSD-bitstamp
python -m research.select_live   --data BTCUSD-bitstamp        # -> bots/bot1..5.toml
```
